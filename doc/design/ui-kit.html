How the system is built

DESIGN.md v0.3

Three tiers, one token source. Nothing in ui/ hardcodes a visual value — a check script fails the build on stray hex, arbitrary spacing or raw ms outside the token layer.

1Token layer— ui/src/index.css, Tailwind v4 @theme, no config file
2shadcn primitives— components/ui/, new-york style, in sync with the registry

class merge via cn()
Product stance. An operational control plane — org charts, tasks, heartbeat runs, budgets, approvals, audit logs. Every screen answers, in order: what is happening, does it need me, what do I do about it. Density comes from information, never from chrome.

Status system

One vocabulary, learned once. Each status owns a base hue; the chip, the fill and the glyph all derive from it, so a status reads the same in a row, a badge, a chart and a log. Glyph hues are separately tuned to clear WCAG 3:1 against the page.

Motion

index.css :root · never @theme inline

Two house curves and five durations; every animated surface references them, and a check script rejects a raw ms or cubic-bezier anywhere in components. Motion lives in :root rather than @theme inline precisely so a dev tweak panel can retune the whole thread at runtime.

Two curves, no thirdExpo is the signature — things arrive fast and settle. Standard is the material curve for state changes that shouldn't draw the eye.
TokenValueWhere it's spent
--motion-duration-instant80msHover, focus, press
--motion-duration-fast160msBubble enter, status swap, plan check
--motion-duration-base240msMarker enter, tool card, diff reveal, line scroll
--motion-duration-slow360msCount tween
--motion-duration-deliberate520msReserved — a change the operator must notice
--motion-turn-fold380msA finished turn folding into its summary line
--motion-interstitial-dwell4000msHow long a finished update sits before sliding away
--motion-approval-pulse1.6sApproval card waiting on a human
--motion-streaming-cursor-blink1.1sStreaming cursor
--motion-cot-line-stagger40msPer-line delay in reasoning output
24 motion tokensPrimitives plus state-scoped aliases, so the tweak panel can group knobs by the state they affect. Under prefers-reduced-motion every duration collapses to 0ms at the token level — components need no branch.
